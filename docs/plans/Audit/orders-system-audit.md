## 1. How the Orders System Works

### The Two-Tier Model

The Orders system uses a **two-tier ordering model**:

1. **JPOs (Job Parts Orders)** — Field workers request parts for a specific job. These go through an approval workflow before any money is spent.
2. **POs (Purchase Orders)** — Once a JPO is approved, the office creates POs directed at specific suppliers. POs can also be created standalone for general warehouse restocking.

On top of that, there are **Returns** (job-to-warehouse and warehouse-to-supplier RMAs) and a **Procurement** dashboard for strategic reorder planning.

### JPO Lifecycle

```
Field Worker creates JPO (draft)
    → Submits for approval (pending_approval)
    → Manager approves (approved) or rejects (back to draft)
    → Office generates PO(s) from approved lines (ordering)
    → PO lines received → JPO tracks received quantities
    → All lines fulfilled → JPO closed
```

## 4. Data Flow Summary

### Creating a JPO and Getting Parts Delivered

```
1. Field worker opens NewPartsRequestPage
2. Selects a job, searches parts via CatalogBrowser/PartSearchModal
3. Adds line items with quantities and priorities
4. Saves as draft → createJPO() API call
5. Submits for approval → submitJPO()
6. Manager approves on JPODetailPage → reviewJPO({action: 'approve'})
7. Office opens GeneratePOsPage → groups lines by supplier
8. Creates PO(s) → createPOFromJPO()
9. Submits PO to supplier → submitPO()
10. Shipment arrives → ReceiveShipmentPage → receiveByPO()
11. Stock movements created, staging zone assigned
12. Items distributed from staging to final location
```

**Proposal:**
- **Scan-first flow:** Worker scans a part barcode → system shows all open PO lines for that part → worker enters qty received NOTE: Yes, implementing a scan-first flow for receiving shipments would be a great improvement for warehouse workers. Instead of having to select a supplier or PO first, workers can simply scan the barcode of the part they are receiving, and the system can automatically pull up all open PO lines for that part.
